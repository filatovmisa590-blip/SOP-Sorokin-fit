# Сайт «Ведение с командой» — Sorokin Fit

## Что внутри

- **index.html** — сама страница
- **support.js** — движок, который её рисует (обязателен)
- **assets/** — логотипы и фотографии кейсов (обязательны)

Все три пункта должны лежать рядом, в одной папке. Никакой заглушки при загрузке
здесь нет — страница открывается сразу.

## Как выложить на GitHub Pages

1. Создайте новый репозиторий на github.com (например `ksf-site`), Public.
2. Загрузите содержимое этой папки в корень репозитория: файл `index.html`,
   файл `support.js` и папку `assets` целиком.
   Проще всего: на странице репозитория → **Add file → Upload files** →
   перетащить всё сразу → **Commit changes**.
3. Откройте **Settings → Pages**.
4. Source: **Deploy from a branch**, Branch: `main`, папка `/ (root)` → **Save**.
5. Через 1–2 минуты сайт будет доступен по адресу
   `https://<ваш-логин>.github.io/<название-репозитория>/`

### Свой домен

Settings → Pages → Custom domain — укажите домен. Затем у регистратора домена
добавьте CNAME-запись на `<ваш-логин>.github.io`.

## Что подгружается из интернета

- **Видеоинтервью** — три плеера Kinescope (видео всегда стримится с их сервера).
- **Фото галереи результатов** (8 квадратных снимков) — лежат на Tilda CDN.
- **Шрифты** Unbounded, Manrope, Caveat — с Google Fonts. Если недоступны,
  подставится системный шрифт, вёрстка не сломается.

Фотографии Дениса и все кейсы (Дмитрий, Алексей, Николай, Владимир) лежат
локально в `assets/` — от Tilda они не зависят.

## Ссылки на кнопках

Все кнопки ведут на `https://sorokin-fit.com/contacts`.
Чтобы поменять — найдите в `index.html` строку `sorokin-fit.com/contacts`
и замените на нужную.
