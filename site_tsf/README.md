# Сайт «Ведение с командой» — Sorokin Fit

## Что внутри

- **index.html** — весь сайт одним файлом. Внутрь уже вшиты стили, скрипты, все фотографии
  Дениса, кейсы и галерея результатов. Ничего дополнительно загружать не нужно.
- **assets/** — исходные фотографии в оригинальном виде. Для работы сайта они **не требуются**,
  лежат на случай будущих правок.

## Как выложить на GitHub Pages

1. Создайте новый репозиторий на github.com (например `ksf-site`), Public.
2. Загрузите в корень репозитория файл **index.html** (можно просто перетащить его
   в окно браузера на странице репозитория → Commit changes).
3. Откройте **Settings → Pages**.
4. В блоке «Build and deployment» → Source выберите **Deploy from a branch**,
   Branch: `main`, папка `/ (root)` → Save.
5. Через 1–2 минуты сайт будет доступен по адресу
   `https://<ваш-логин>.github.io/<название-репозитория>/`

### Свой домен

В Settings → Pages → Custom domain укажите домен, затем у регистратора домена
добавьте CNAME-запись на `<ваш-логин>.github.io`.

## Что подгружается из интернета

Всё, кроме двух вещей, лежит внутри файла:

- **Видеоинтервью** — три плеера Kinescope. Видео всегда стримится с их сервера,
  вшить его в файл нельзя (иначе файл весил бы гигабайты).
- **Шрифты Unbounded, Manrope и Caveat** — с Google Fonts. Если Google недоступен,
  браузер подставит системный шрифт; вёрстка не сломается.

## Ссылки на кнопках

Все кнопки ведут на `https://sorokin-fit.com/contacts`.
Чтобы поменять адрес — найдите в index.html строку `sorokin-fit.com/contacts`
и замените на нужную (встречается несколько раз).
